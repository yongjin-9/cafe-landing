# cafe-landing ☕

가상의 동네 카페 **카페 소담**을 소개하는 한 페이지짜리 랜딩 페이지입니다.
별도의 프레임워크나 빌드 과정 없이 HTML과 CSS만으로 만들었습니다.

## 폴더 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 페이지 본문 (섹션 구조와 텍스트) |
| `style.css` | 디자인 (색상, 레이아웃, 반응형 스타일) |
| `README.md` | 이 문서 |

## 페이지 구성

1. **상단 내비게이션**: 스크롤해도 따라오는 메뉴 (소개 · 메뉴 · 오시는 길)
2. **히어로**: 카페 슬로건과 바로가기 버튼
3. **소개**: 매일 로스팅 · 직접 굽는 디저트 · 머물고 싶은 공간
4. **시그니처 메뉴**: 음료와 디저트 6종, 가격 포함
5. **오시는 길**: 주소, 영업시간, 휴무일, 첫 방문 혜택 안내
6. **푸터**

## 특징

- 순수 HTML + CSS, 외부 의존성은 Google Fonts(고운바탕, Noto Sans KR)뿐
- 모바일·태블릿·데스크톱 반응형 레이아웃
- 색상 값을 `style.css` 상단의 CSS 변수(`:root`)로 모아 두어 테마 변경이 쉬움

## 실행 방법

`index.html` 파일을 브라우저로 열면 바로 볼 수 있습니다.

## 수정 가이드

- **카페 이름·문구 변경**: `index.html`의 텍스트를 수정
- **메뉴·가격 변경**: `index.html`의 `#menu` 섹션 안 `<li>` 항목을 수정·추가
- **색상 변경**: `style.css`의 `--accent`, `--bg` 등 변수 값을 수정
- **주소·영업시간**: `#visit` 섹션의 `○○` 자리 표시를 실제 정보로 교체

> 주소와 연락처는 실제 정보가 아닌 예시용 자리 표시입니다.
